# Changelog

## 0.1.0

- Initial `createTunnel()` API with lazy `In` registration and destination `Out` rendering.
- Stable multiple-entry ordering and reactive `order` support.
- Single active destination semantics with deterministic waiting-`Out` promotion.
- DOM/custom-renderer unit coverage and bidirectional TresJS browser coverage.
- Packed-package compatibility coverage for Vue 3.4.0 and 3.5.42.
